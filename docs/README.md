# GigPies documentation

GigPies combines audio mixing, PA processing, performer monitors, recording and
lighting with separate human-operated audio and lighting consoles.
Start with [product status](STATUS.md) and the
[system architecture](architecture/ARCHITECTURE.md).

| Documentation | Contents |
|---|---|
| [Architecture](architecture/README.md) | System boundaries, module ownership, consoles and planned performer interaction |
| [Guides](guides/README.md) | Running local services and using offline mixing, analysis and delivery tools |
| [Reference](reference/README.md) | Signal paths, parameters, protocols, authority, persistence and recovery |
| [Acceptance](acceptance/README.md) | Validated software scope, measured hardware limits and outstanding qualification |
| [Development](development/README.md) | Building, testing, lab operation, local media and publication |

Implemented, software-validated and physically verified behavior are distinct.
The reference system targets 16 analog inputs and 18 analog outputs at 48 kHz;
software test profiles do not define product capacity limits.

Historical plans, execution prompts, superseded drafts and experiment results live
in the [archive](archive/README.md). They are retained for provenance and are not
current operating instructions.
